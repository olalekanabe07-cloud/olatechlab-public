# Contributing to OlatechLab Public

Thanks for your interest in contributing.

## Before You Start

- Review the repository purpose in [README.md](./README.md).
- Search existing issues and pull requests before opening new ones.
- For larger ideas, open a feature request first to align scope.

## How to Contribute

1. Fork the repository.
2. Create a focused branch for your change.
3. Keep changes scoped and technology-neutral unless an issue requires otherwise.
4. Update related documentation when behavior or usage changes.
5. Open a pull request with a clear summary of:
   - Problem being solved
   - Approach taken
   - Validation performed

## Contribution Standards

- Keep submissions professional and constructive.
- Avoid introducing proprietary or sensitive information.
- Do not include secrets, credentials, API keys, or internal infrastructure details.
- Prefer reusable, maintainable solutions over one-off implementations.

## Pull Request Checklist

- [ ] Changes are focused and relevant to the issue
- [ ] Documentation is updated when needed
- [ ] No sensitive information has been added
- [ ] Existing tests/checks (if applicable) pass locally

## Code Review

All contributions are reviewed for quality, safety, and project fit. Feedback may request revisions before merge.

By contributing, you agree that your submissions may be modified and distributed under this repository's license.

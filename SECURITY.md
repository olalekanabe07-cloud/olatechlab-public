# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it responsibly:

1. **Do not** open a public issue with exploit details.
2. Submit a private report using GitHub's security advisory workflow for this repository, if available.
3. If private advisory reporting is unavailable, use the contact channel at [https://olatechlab.com](https://olatechlab.com) and include "Security Report" in your message.

## What to Include

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation (if known)

## Response Process

OlatechLab will review reports, validate findings, and coordinate remediation. We aim to acknowledge valid reports promptly and provide updates during triage.

## Safe Disclosure

Please allow time for investigation and remediation before public disclosure.
